# Метки triage

Скиллы говорят о пяти канонических ролях triage. Этот файл сопоставляет роли с реальными строками меток, используемыми в трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение |
| ------------------------- | --------------------- | -------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить задачу |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительную информацию |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для AFK-агента |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком |
| `wontfix`                 | `wontfix`             | Не будет исправляться |

Когда скилл упоминает роль (например, «применить метку AFK-ready triage»), использовать соответствующую строку метки из этой таблицы.

Редактировать колонку «Метка в нашем трекере» под фактический словарь.
